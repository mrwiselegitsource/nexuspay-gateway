NexusPay Hosted Checkout

Welcome to the NexusPay developer documentation. NexusPay is a secure, highly-converting payment gateway designed to help you accept payments instantly without the burden of PCI compliance.

Our Hosted Checkout solution redirects your customers to our secure, bank-grade payment pages, processes their card, and redirects them back to your application.

Quickstart Guide

Integrating NexusPay takes less than 5 minutes. Follow this standard workflow:

  1. Your customer clicks "Buy Now" on your product page.
  2. Your backend makes an API call to POST /api/checkout/sessions to define what the customer is buying.
  3. NexusPay returns a secure url.
  4. You redirect the customer to that url.
  5. NexusPay handles the credit card collection and securely redirects the user back to your success page.

Example Integration (JavaScript)

// On your frontend when "Buy Now" is clicked:
const baseUrl = window.location.origin;
const response = await fetch('/api/checkout/sessions', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        line_items: [{ 
            price_data: { unit_amount: 9900 } // Amount in cents ($99.00)
        }],
        success_url: `${baseUrl}/success.html`,
        cancel_url: `${baseUrl}/cancel.html`
    })
});

const session = await response.json();
// Redirect customer to NexusPay Hosted Checkout
window.location.href = session.url;

POST Create a Checkout Session

Creates a new payment session. You must call this from your server or frontend to initiate a transaction.

Endpoint: /api/checkout/sessions

Request Body (JSON)

Parameter Type Description
line_items Array A list of items the customer is purchasing. Must contain price_data.unit_amount in cents.
success_url String The absolute URL to redirect the customer to after a successful payment.
cancel_url String The absolute URL to redirect the customer to if they cancel the checkout.

Response

{
  "url": "https://your-project.vercel.app/checkout.html?session_id=cs_mock_12345"
}

GET Retrieve a Session

Fetch the details of an existing session using its unique ID. Used internally by the checkout page.

Endpoint: /api/checkout/sessions/:id

Response

{
  "id": "cs_mock_12345",
  "amountTotal": 9900,
  "status": "open",
  "successUrl": "https://your-project.vercel.app/success.html"
}
